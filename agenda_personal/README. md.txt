# Agenda Personal Web

## Descripción del Proyecto
Aplicación web desarrollada en PHP y MariaDB que permite la gestión segura de una agenda de contactos personal mediante autenticación de usuarios, manejo de sesiones y aislamiento de datos por usuario.

## Tecnologías Utilizadas
* PHP
* MariaDB / MySQL
* HTML / CSS
* XAMPP

## Requisitos
* XAMPP (Apache y MySQL)

## Instalación
1. Coloca la carpeta del proyecto en `C:/xampp/htdocs/`.
2. Importa el archivo de la base de datos en phpMyAdmin.
3. Accede a `http://localhost/agenda_personal/` en tu navegador.
